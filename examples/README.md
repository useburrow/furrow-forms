# Examples

One folder per stack: the recipe (`README.md`) and the form snippet or
prompt from the matching page on furrowforms.com. Replace `fp_k7m2` with a
real form key — your agent will do that for you if you paste:

```
Fetch furrowforms.com/ai and set up forms for this site.
```
